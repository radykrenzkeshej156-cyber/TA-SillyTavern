📘 CSS 适配规范：
1. 核心变量覆盖：通过 :root { ... } 快速改全套色系：
• --st-primary: 主强调色
• --st-accent: 辅助色
• --st-bg: 全局底色
• --st-char-bubble: NPC卡发言气泡背景
• --st-user-bubble: TA马甲发言气泡背景
2. 类名选择器直接美化：
• .char-bubble: NPC角色卡对话框（可加圆角/阴影/毛玻璃）
• .user-bubble: TA马甲发言框
• .owner-real-os: 屏幕外真实内心戏小暖条
• .wx-card-item: 列表横向卡片项
• .action-text: *动作神态描写* 的斜体颜色
3. 自定义背景图：
#st-root { background-image: url('你的图片地址') !important; background-size: cover; }
